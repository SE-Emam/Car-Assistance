# خطة العمل التنفيذية — مشروع Car Assistance
**النسخة:** 1.0 · **التاريخ:** نوفمبر 2026 · **الحالة:** بانتظار الاعتماد

هذه الخطة هي المرحلة التنفيذية بعد اعتماد وثيقة المعمارية (SE209). كل مهمة هنا قابلة للتنفيذ والتحقق: لها مخرج ملموس ومعيار قبول. الفريق خمسة أعضاء بحسب توزيع الملكية المعتمد في الوثيقة المعمارية.

---

## فريق العمل والملكية

بحسب توزيع الملكية المعتمد في الوثيقة المعمارية (SE209) — كل عضو يملك شريحة رأسية من النظام:

| العضو | الملكية | الخدمات المملوكة |
|---|---|---|
| **أحمد محمد بكري** | نواة الباك إند وبوابة API | بوابة API، خدمة أكواد الأعطال، تكامل Supabase Auth |
| **رانيا مدحت محمد** | الواجهة وتجربة المستخدم | الواجهة الويب، اختبار قابلية الاستخدام، إتاحة الوصول |
| **نادر أحمد سعيد** | الذكاء الاصطناعي وقاعدة المعرفة | خدمة التشخيص، خدمة RAG، بوابة LLM، تصميم المطالبات |
| **محمد أحمد سعيد** | تحليل الصور بالذكاء الاصطناعي (VLM) | خدمة تحليل الصور، تصميم وتقييم مطالبات VLM، مجموعة صور الاختبار |
| **إيمام أحمد وحيد** | DevOps والبيانات والتكامل | Service Locator، طبقة البيانات، CI/CD، المراقبة، النشر |

> في جداول المراحل أدناه يُشار للمالك بالاسم الأول اختصارًا (أحمد = أحمد محمد بكري، وهكذا).

## 0. نطاق هذه الخطة

| العنصر | القرار |
|---|---|
| **مجلد المشروع** | `Car-Assistance-App/` منفصل عن مجلد الوثائق الأكاديمية |
| **الواجهة** | HTML/CSS/JS متعددة الصفحات (MPA) — **Mobile-First** إلزاميًا |

| **سيارة العرض التجريبي** | Mercedes-Benz B-Class (W245) 2005–2011 — بيانات حقيقية موثقة |
| **العربية** | الواجهة في هذه المرحلة إنجليزية؛ التعريب بند مخطط (المرحلة 6) |

## 3. نطاق الديمو الحالي (W245) — ما يشمل وما لا يشمل

**يشمل:** بيانات موثقة من ويكيبيديا/مصادر عامة لسيارة B-Class W245: محركات M266 بنزين (B160–B200 Turbo)، OM640 ديزل CDI (B180/B200 CDI)، B170 NGT؛ ناقل 5/6 سرعات يدوي أو CVT؛ أرضية Sandwich. الأكواد المزروعة (~24) تغطي أعطاله الشائعة الموثقة فعليًا (دواسات شمع التسخين P0670–P0674، حساس زاوية التوجيه، P0300 اختلال إشعال، P0171 خلقة خليط، P0128 منظم حرارة، P0410 ضخ هواء ثانوي، P2004 مشعاع manifold flap، مقاومة منفاخ التكييف، بطارية/SAM...).

**لا يشمل (مقصودًا):** لا استدعاءات API حقيقية — الشات تدفق مكتوب، الصور محاكاة، الخرائط ترتيب مسافات محسوب. هذا ديمو اعتماد وليس منتجًا: **الهدف عرض التجربة قبل بناء الباك إند**.
